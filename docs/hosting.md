# Hosting a Forza Live server

**[FH1-ReImagined/forza-live, `docs/hosting.md`](https://github.com/FH1-ReImagined/forza-live/blob/main/docs/hosting.md)**.

so the guide is also at [`server/docs/hosting.md`](../server/docs/hosting.md).

The reference is in the same repository: [`configuration.md`](https://github.com/FH1-ReImagined/forza-live/blob/main/docs/configuration.md) (every option),

[`website-data.md`](https://github.com/FH1-ReImagined/forza-live/blob/main/docs/website-data.md) (what the server publishes for a website).
